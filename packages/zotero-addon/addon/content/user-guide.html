TRANSLATE BRIDGE FOR ZOTERO · 1.0.6

三步开始使用

在论文网页中阅读和做笔记，并把高亮、中文翻译与个人笔记同步到 Zotero PDF 的对应原文位置。

先确认：只需安装 Translate Bridge for Zotero 两端

  • 必需：Zotero 桌面版 + 本包 Zotero 插件；桌面 Chrome 138+ + 本包 Chrome 扩展，两端运行在同一电脑。
  • 同步高亮必需：Zotero 中已有对应论文和带文字层的 PDF；纯扫描图片不能直接定位。
  • 翻译条件：整页中文使用 Chrome 自带翻译；扩展内英译中及部分反查使用 Chrome 本地 Translator 与英中语言包，首次可能下载，实际可用性取决于设备和网页。Chrome 官方说明
  • 可选：Zotero Connector 方便收录论文，不是同步的必需组件。
  • 无需安装：LLM-for-Zotero、PDF Translate、Style、Better BibTeX、OCR 插件；无需 AI API key、Node.js 或 Python。
Zotero 端已验证：Windows + Zotero 9.0.6 / 10.0.3。插件声明支持 Zotero 7–10，其他版本和 macOS/Linux 尚未完成同等实机验证，建议先测试一篇论文。

1. 安装 Zotero 插件

  1. 打开 Zotero，点击“工具 → 插件”。
  2. 点击右上角齿轮，选择“从文件安装插件”。
  3. 选择 Translate-Bridge-Zotero-1.0.6.xpi。
  4. 完全退出 Zotero，再重新打开。
  5. 点击“工具 → Translate Bridge for Zotero → 复制配对码”。

2. 安装 Chrome 扩展

  1. 在 Chrome 地址栏打开 chrome://extensions/。
  2. 开启右上角“开发者模式”，点击“加载已解压的扩展程序”。
  3. 选择整个 Translate-Bridge-Chrome-1.0.6 文件夹。
  4. 进入 Translate Bridge for Zotero 的“详情 → 扩展程序选项”。
  5. 粘贴配对码，点击“保存并测试”。
建议点击 Chrome 工具栏的拼图图标，把 Translate Bridge for Zotero 固定在工具栏。

3. 阅读、做笔记并同步

选择完整句子翻译并做笔记同步到 Zotero
  1. 在 Zotero 选中论文，点列表顶部带蓝色桥形图标的“网页阅读”；也可右键选“Paper Bridge · 在浏览器中阅读”。
  2. 网址由系统默认浏览器打开；如果不是 Chrome，请复制到 Chrome。首次翻译前先让英文正文完整加载。
  3. 可以直接选择英文，也可以用 Chrome 整页翻译后选择中文。
  4. 选择一个完整句子或连续段落，点击“翻译并做笔记”。
  5. 选择高亮颜色，可填写个人笔记，然后点击“同步到 Zotero”。
  6. 点击“打开选中段落”可定位当前段落；同步成功后会直接定位到该高亮。
批注中“我的笔记”排在最上方，中文翻译在下方。Ctrl + Enter 可同步，Esc 可关闭侧栏。
“打开这篇文章”始终可用；“打开选中段落”在未选择文字时为灰色，选中并恢复出英文锚点后会变亮。

引导、更新与使用范围

  • 顶部“?”或“工具 → Translate Bridge for Zotero → 开始使用与配对…”可查看引导；“用户手册与依赖说明…”可离线打开本手册。
  • 定位覆盖 PDF 全文；首次同步需等待全文读取，之后复用本机会话缓存。 支持两侧都有足够文字的相邻两页跨页高亮。纯扫描或加密 PDF、三页以上选区及网页/PDF 版本差异可能导致定位失败。
  • 批注保存为 Zotero 原生高亮，不会覆盖原 PDF；分享带批注 PDF 请使用 Zotero 导出功能。
  • 更新 Zotero 端：安装新版 XPI 并重启。更新 Chrome 端：用新版文件覆盖原加载文件夹，在扩展管理页点“重新加载”，再刷新论文页；换文件夹加载时需要重新配对。

首次验收

  1. 点击 Chrome 扩展设置中的“保存并测试”，确认连接成功。
  2. 选择 PDF 讨论部分的一句正文，写一条测试笔记并同步；核对 PDF 高亮位置、译文、笔记和颜色。
  3. 点“打开选中段落”，确认定位正确，再开始正式使用。
把整个 ZIP 发给同事即可。每位同事在自己电脑生成配对码，不要分享个人配对码、浏览器配置或文库。

遇到问题

  • Zotero 暂不可用：确认 Zotero 已打开；重新复制配对码并保存测试。
  • 未找到文献：确认 Zotero 中已有该论文，DOI 或标题正确，并附有 PDF。
  • 中文无法定位：先刷新英文原始页面，再开启整页翻译，并选择完整句子。
  • Extension context invalidated：刷新当前论文网页。
  • “打开选中段落”是灰色：尚未选择文字，或扩展仍在恢复对应英文原文。
优先环境：Windows、Zotero 9.0.6 或 10.0.3、桌面 Chrome 138+。Translate Bridge for Zotero 只把批注发送到本机 Zotero；Chrome/Google 翻译的数据处理遵循其服务规则。
