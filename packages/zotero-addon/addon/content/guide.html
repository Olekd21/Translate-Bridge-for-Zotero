Translate Bridge for Zotero

网页阅读，批注回到 PDF

先安装两端，再配对一次。日常选中论文，点顶部的“网页阅读”就能开始。

  1. 在 Chrome 安装配套扩展

    解压安装包，按用户手册加载 Translate Bridge for Zotero Chrome 文件夹，并将扩展固定到工具栏。

    只需 Translate Bridge for Zotero 两端，不需要额外安装 Zotero 翻译或 AI 插件。

  2. 把 Zotero 与 Chrome 配对

    复制配对码 → Chrome 的 Translate Bridge for Zotero 设置 → 粘贴 → “保存并测试”。每位同事使用自己电脑生成的配对码。

  3. 选论文，开始阅读

    在 Zotero 选中一篇已有 PDF 的论文。打开网页后，用 Chrome 整页翻译，选择句子、写笔记，再点“同步到 Zotero”。

    链接由系统默认浏览器打开；若不是 Chrome，请把网址复制到 Chrome。

Zotero 保持运行，批注通过本机连接同步。

支持范围与常见问题都在手册中。
