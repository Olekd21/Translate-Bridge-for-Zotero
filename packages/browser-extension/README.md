# Translate Bridge for Zotero Chrome 扩展

## 加载

1. 解压安装包，找到 `Translate-Bridge-Chrome-1.0.0` 文件夹。
2. 打开 `chrome://extensions/`，开启“开发者模式”。
3. 点击“加载已解压的扩展程序”，选择解压后的文件夹。
4. 安装 Zotero 插件后，从 Zotero“工具 → Translate Bridge for Zotero → 复制配对码”获取配对码。
5. 在扩展详情中打开“扩展程序选项”，粘贴配对码并测试连接。

## 使用

1. 打开论文 HTML 全文页；若要使用整页翻译，先在英文页面刷新一次。
2. 开启 Chrome 整页翻译，选择一个完整中文句子或连续段落。
3. 点击“翻译并做笔记”，选择高亮颜色，可填写笔记。
   - 直接选择英文时，按钮显示“翻译成中文”，已有译文后显示“重新翻译”。
   - 选择整页翻译后的中文时，按钮显示“匹配英文原文”，成功后显示“重新匹配原文”。
4. 点击“同步到 Zotero”，或按 `Ctrl + Enter`。
5. “打开这篇文章”始终显示；选择文字后“打开选中段落”会启用。同步成功后，它会直接跳到刚创建的 PDF 高亮。

坐标定位覆盖 PDF 全文，首次同步需等待全文读取。中文反查或 PDF 定位不够可靠时会拒绝同步，不会伪装成功或把中文直接写到英文 PDF。
