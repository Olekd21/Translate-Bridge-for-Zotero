# Translate Bridge for Zotero 1.0.0

Chrome 扩展 1.0.0 + Zotero 插件 1.0.0，同一包用于 Zotero 9/10。

改进长论文重复定位性能、短句断词识别、上下文消歧和多栏高亮；保护数字、小数、负号、基因编号与数学比较符号，移除可能误标不同断言的宽松匹配。未写入批注不再报告为同步成功，也不会把旧版接口的未写入记录从待同步队列误删。

8 篇跨领域论文、306 页、1809 个选段分别在 Windows Zotero 9.0.6 和 10.0.3 的原生识别数据上检查；3618 次检查中 3463 次唯一定位，155 次保守拒绝，未观察到错页或越出目标文字块。最终 XPI 的 88 次真实 HTTP 请求及两库各 24 个落盘批注核验通过。42 项命名回归和原有几何套件通过。

数字来自明确测试集，并不保证覆盖所有论文。纯扫描、公式缺字、重复短句、三页以上连续选区仍有限制；未完成全出版商、所有操作系统及完整浏览器交互自动验收。详细方法与限制见[稳定性核查](https://github.com/Olekd21/Translate-Bridge-for-Zotero/blob/v1.0.0/docs/稳定性核查-20260923.md)。

更新：安装新 Zotero XPI 后完全重启；Chrome 重载新扩展目录并刷新论文页。无需 Better Notes 或其他 Zotero 插件。
