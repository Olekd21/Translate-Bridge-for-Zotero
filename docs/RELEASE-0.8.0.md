# Translate Bridge for Zotero 0.8.0 · 译桥

连接 Chrome 内置 Google 翻译与 Zotero PDF 批注。本次修复讨论、结论等后半部分无法定位的问题。

## 下载与更新

下载 **translate-bridge-for-zotero-0.8.0.zip**，解压并打开 **START-HERE.html**。包含 Chrome 扩展 **0.8.0**、Zotero 插件 **0.6.0** 和离线手册。

**全文定位修复在 Zotero 端，必须安装新的 XPI。** 在 Zotero“工具 → 插件”选择“从文件安装插件”，安装本包的 `Translate-Bridge-Zotero-0.6.0.xpi` 并重启。Chrome 端用新版文件覆盖原加载文件夹，在扩展管理页重新加载，再刷新论文网页。原路径更新可保留配对配置。

扩展设置中的“保存并测试”现在会识别旧 Zotero 插件；连接成功但仍旧版本时，会提示更新。

## 修复与改进

- PDF 定位覆盖整篇文档，不再限于前 5 页。在内存中分批读取并恢复原页序，保持原 PDF 不变。
- 加入本机会话缓存，并在 PDF 文件变化后重新读取；读取不完整或失败不会被当成“全文中没有找到”。
- 区分读取失败、找不到对应文字和多处相似文字，提供对应提示。
- 合并同一位置的重复匹配结果；遇到不同位置的歧义时不写入批注。
- 保留相邻两页的跨页定位，包括内部读取批次边界两侧的页面。

## 验证与使用范围

在 Windows + Zotero 9.0.6 上对 22 页真实论文完成只读验证：读取全部页面，讨论部分完整段落唯一定位到第 13 页，原第 2–3 页跨页段落仍可定位；前 5 页的原生识别坐标与旧读取方式一致。未在正式文库创建测试批注。

全文分批读取、缓存失效、失败处理、歧义拒绝、跨页几何以及既有匹配和阅读界面回归通过，构建及分发包校验通过。

需要可检索文字的 PDF；纯扫描、加密文件、网页与 PDF 版本不同或跨三页以上的选区仍可能无法定位。Chrome 需 138+；其他系统与 Zotero 版本尚未完成同等实机验证。新增 pdf-lib 已打包，无需用户安装额外插件或开发工具。
