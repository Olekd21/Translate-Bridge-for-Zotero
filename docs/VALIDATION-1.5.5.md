# Translate Bridge for Zotero 1.5.5 验证记录

本次针对用户明确指定的 VEGF-C/VEGFR-3 压力超负荷论文（2021，DOI 10.1002/ctm2.374），继续使用 Chrome 原生 Google 翻译。Zotero 文库中该论文链接为 https://pmc.ncbi.nlm.nih.gov/articles/PMC7989711/ 。未将文本交给其他翻译服务。

## 查明的原因和修复

1. 英文快照在清理空白后断句，DOM 标记却在原始换行文本上再次断句。真实引言段落被分别算成 13 句与 61 片，旧逻辑直接放弃所有标记。现在只对不可变快照断句，保留字符投影，将同一组句界还原到 DOM；覆盖换行、引用空白、NBSP 与 UTF-16 偏移。
2. Google 可以拆分并搬动普通行内 marker，科学上下标和引用附近尤其明显。句子现在使用有宽度限制的 inline-block 容器，约束原生翻译的处理单位。会比原文更频繁换行，未隐藏英文来源或丢弃引用。
3. PMC 的 `ctm2374-bib-*` 引用未被识别，选句捎带前一句引用号时被误判半句。现在通过同页文献列表的实际 DOM 身份识别引用；仅选择引用的交集不参与正文覆盖。图号、数值、普通链接与未知正文仍不能被静默跳过。
4. 句末引用在缓存单句复核时被单独切开；`Inc. (1:2000).` 也被拆成无语言信息的独立稀释比例。统一句末引用和有括号后缀的厂家缩写边界，真实句末 `Inc. Controls...` 仍断开。
5. 一个英文句子被译成多句中文时，尾随真正引用不再阻止现有的完整原句确认。仍展示补充范围，由用户点击确认，不自动把选区扩大后假称精确映射。

对比实验：把科学 sup/sub 排除翻译，会令 Google 在基因名称附近插入多余句号，完整原句确认数量从 16 增至 114，故未采用。完全取消引用保护又导致本轮 51 个中文选句失败，故只保护实际文献引用链接。最终译文未发现字面 `<sup>`；这不是对其他网页所有翻译字符的保证。

## 真实文章、真实 Google 翻译

从 PMC 原始 HTML 建立隔离页面，仅加测试编号、产品内容脚本及断开 Zotero 的测试接口。使用 Google Chrome、Chrome 内置 Google 翻译，每个来源句实际滚动到可视区以触发延迟翻译；未用手写中文替代这一层测试。

范围包括摘要、图形摘要、正文各章节及图注，共 48 个文字块，其中 9 个图注块。不包括参考文献条目、表格单元格、网页导航及补充材料另册。

| 检查 | 结果 |
| --- | --- |
| 不可变英文来源句 | 356/356 建立并精确恢复 |
| 中文整段 | 48/48 精确恢复整段英文 |
| 中文句号划分的选句 | 364 个；348 直接对应，16 需确认完整原句 |
| 相邻两句选区 | 316/316 直接或经完整原句确认完成 |
| 未触发翻译的来源句 | 0 |
| 单次映射耗时（本机隔离测试） | 最慢约 16.4 ms |

16 个选句对应 8 个被 Google 拆开的英文长句，不属于 16 个英文定位失败。它们不能宣称为“无需确认、逐个中文分句精确对应英文分句”。完整原句须经用户核对后采用。

## 实际 MV3 扩展侧栏

在独立 Chromium 中真正加载 1.5.5 MV3 扩展，先从原始英文网页建立来源，再回放上述实际 Google 翻译所得的 DOM。没有同时注入测试内容脚本；检查仅存在一个插件根节点。所有 48 整段与 364 中文选句共 412 项通过，验证英文显示、定位按钮状态，以及 16 次完整原句确认前后状态。未点击同步按钮或写入正式文库。

这一层是实际译文的回放，不是 MV3 与 Google 翻译同一浏览器内的实时端到端测试。原生 Google 层使用内容脚本和断开的 Zotero 测试接口；版本号升级前后执行代码已逐字核对，仅版本标识变化。没有在用户正式 Chrome 中替换扩展。

## 回归及性能

- 344 项跨领域 DOM 结构矩阵、46 项完整来源范围回归通过。矩阵里的其他领域仍是占位中文，不能作为真实翻译语义验证。
- 不可变来源快照、13 句跨 ID 行内结构、数字引用、克隆引用、边界证据、来源归属与高亮生命周期检查通过。
- 200 段、600 来源句、25 次段落替换后来源身份不增长并恢复原文，约 369 ms。
- 高亮稳定性：无关页面更新 0 额外请求、0 文本遍历、0 高亮缺失；单段变化只 1 次遍历。
- 手动问题记录、导出、回访和人工复核使用真实 MV3 入口复验；不增加自动保存错误。
- 全部项目测试、扩展检查、TypeScript/XPI 构建、发行包检查见 `.cache/vegfc155/build-release.log` 和 `verify-release.log`。

## 更新与边界

1.5.4 用户此次只需更新 Chrome 扩展。将新文件覆盖原加载目录，扩展管理页点重新加载；不要卸载，以保留本地问题记录。已有论文须恢复英文、刷新、重新 Google 翻译，旧页旧标记不会因关闭侧栏而更新。

修复适用于共用句界与来源代码，并非针对 DOI 硬编码。验证结论限于上述文章、页面与当前 Google 输出；不保证 Google 后续 DOM 变更或所有出版商页面永久 100% 成功。未逐条在正式 Zotero PDF 创建批注，PDF 同步链路仍需用户原安装环境核验。未改动正式文库、正式浏览器配置，未发布 GitHub。此前侧栏刷新按钮、遮挡和左侧弹窗建议不在本次改动范围。
