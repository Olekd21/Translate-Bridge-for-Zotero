# 译桥 1.0.2：中文单句定位

修复 Chrome 整页翻译后整段能定位、段内单句容易匹配失败的问题。在英文页面阶段保存句子与原文的对应关系，翻译保留对应节点时，完整单句和连续几句可直接找回英文，不依赖再次翻译后比较文字相似度。没有针对特定论文或句子的白名单。

同时修复 `Cannot read properties of null (reading 'matches')`：页面移除文字节点后，观察回调跳过已脱离页面的节点，继续缓存后续有效段落。侧栏顶部显示版本号，方便确认当前标签页已加载新版。

Chrome、Zotero 和完整包版本均为 **1.0.2**，发行附件仅为 Chrome ZIP、Zotero XPI、完整 ZIP，不包含安装器。

## 更新

1. Chrome ZIP 解压覆盖原扩展目录，在 `chrome://extensions/` 重新加载译桥；保留原加载路径。
2. 恢复论文英文并刷新页面，再开启 Chrome 自带翻译；确认译桥侧栏顶部显示 **1.0.2**。
3. Zotero 通过“工具 → 插件 → 齿轮 → 从文件安装插件”安装 XPI，正常重启。此次单句修复不需要重新配对。
