# Translate Bridge for Zotero 用户手册

Translate Bridge for Zotero 用于在论文网页中阅读和做笔记，并把高亮、中文翻译和个人笔记同步到 Zotero PDF 的对应原文位置。

## 安装前：需要哪些组件？

| 组件 / 条件                                        | 是否必需                           | 用途                                                              |
| -------------------------------------------------- | ---------------------------------- | ----------------------------------------------------------------- |
| Zotero 桌面版 + 本包的 Translate Bridge for Zotero Zotero 插件    | 必需                               | 查找本机 PDF、创建高亮与保存笔记；同步时保持 Zotero 运行。        |
| 桌面 Chrome 138+ + 本包的 Translate Bridge for Zotero Chrome 扩展 | 必需                               | 网页选区、译文与笔记侧栏；与同一电脑上的 Zotero 配对。            |
| Zotero 中已保存的对应论文与可检索文字的 PDF        | 同步高亮必需                       | PDF 需有可用文字层；纯扫描图片不能直接定位。                      |
| Chrome 自带整页翻译                                | 读中文网页时使用                   | 不必额外安装“谷歌翻译”扩展；能否翻译取决于 Chrome 和网页。        |
| Chrome 本地 Translator API 与英中语言包            | 扩展内英译中、部分中文反查兜底使用 | 首次可能下载语言包；版本满足不代表当前设备或网页一定可用。        |
| Zotero Connector                                   | 可选                               | 方便把论文网页和 PDF 收入文库；不是 Translate Bridge for Zotero 同步的运行依赖。 |

**不依赖 Better Notes、LLM-for-Zotero、Zotero PDF Translate、Zotero Style、Better BibTeX 或 OCR 插件，不需要 AI API key。** Zotero 内置的 PDF 处理和本地连接服务已随 Zotero 提供；开发用的 toolkit 已打入 XPI，用户无需安装 Node.js、Python 或开发工具。

Zotero 端已验证 Windows + Zotero 9.0.6 / 10.0.3。插件声明支持 Zotero 7–10，但其他版本与 macOS/Linux 未完成同等实机验证，建议先用一篇测试论文试用。Chrome Translator 的功能与语言包要求见 [Chrome 官方说明](https://developer.chrome.com/docs/ai/translator-api)。

## 1. 安装 Zotero 插件

**Zotero 10 用户请使用译桥 Zotero 插件 1.0.0 或更新版本。** 旧版 0.6.0 的 PDF 读取指令与 Zotero 10 不兼容，可能出现配对成功、整篇能打开，但段落定位和同步一直等待。更新 XPI 后必须完全退出并重启 Zotero，清除旧请求状态；重新配对不能修复这个问题。

1. 打开 Zotero，点击顶部菜单“工具 → 插件”。
2. 点击右上角齿轮，选择“从文件安装插件”。
3. 选择安装包中的 `Translate-Bridge-Zotero-1.0.0.xpi`。
4. 完全退出 Zotero，然后重新打开。
5. 点击“工具 → Translate Bridge for Zotero → 复制配对码”。

## 2. 安装 Chrome 扩展

1. Chrome 打开 `chrome://extensions/`。
2. 开启右上角“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择安装包中的整个 `Translate-Bridge-Chrome-1.0.0` 文件夹。
5. 打开 Translate Bridge for Zotero 的“详情 → 扩展程序选项”。
6. 粘贴刚复制的配对码，点击“保存并测试”。

建议点击 Chrome 工具栏的拼图图标，把 Translate Bridge for Zotero 固定在工具栏。

## 3. 日常使用

1. 保持 Zotero 已打开。
2. 选中一篇论文，点击 Zotero 列表顶部带蓝色桥图标的“网页阅读”，或右键“Translate Bridge for Zotero · 在浏览器中阅读”。链接由系统默认浏览器打开；如果不是 Chrome，请把网址复制到 Chrome。第一次使用整页翻译前，先让英文页面完整加载一次。
3. 可以直接选择英文，也可以用 Chrome 整页翻译为中文后再选择中文。
4. 尽量选择一个完整句子或连续段落，然后点击“翻译并做笔记”。
5. 选择高亮颜色，可填写个人笔记，再点击“同步到 Zotero”。
6. 点击“打开选中段落”可定位当前段落；同步成功后会直接定位到该高亮。

“打开这篇文章”始终可用；“打开选中段落”在未选择文字时为灰色，选中并恢复出英文锚点后会变亮。

同步后的批注顺序为：个人笔记在上，中文翻译在下。`Ctrl + Enter` 可同步，`Esc` 可关闭侧栏。

在 Zotero 顶部点击“?”，或“工具 → Translate Bridge for Zotero → 开始使用与配对…”可以随时打开引导；“用户手册与依赖说明…”可离线查看完整手册。

## 4. 常见问题

- **论文整页显示 `403 Forbidden`**：表示网站拒绝本次访问，不能据此判断账号被封。稍后重新打开论文；如出现浏览器验证，在网页中完成。仍失败时，可用无痕窗口或手机网络分别对照，区分浏览器会话和网络出口问题。已下载的 PDF 可继续在 Zotero 中阅读。
- **反查原文遇到 403／429 或验证页**：扩展会说明原因，并暂停重新读取 1 分钟；读取超过 10 秒会中止网络请求。已捕获的英文段落仍可使用。

- **显示“Zotero 暂不可用”**：确认 Zotero 已打开；重新复制配对码并在扩展设置中保存测试。
- **显示“未找到文献条目”**：确认 Zotero 中已有这篇论文，DOI 或标题正确，并且论文条目下附有 PDF。
- **中文选择无法定位**：刷新英文原始页面，让扩展先记录英文；再开启整页翻译，并选择完整句子。
- **按钮含义**：英文选区使用“翻译成中文／重新翻译”；整页翻译后的中文选区使用“匹配英文原文／重新匹配原文”。长段落优先快速匹配，超过 15 秒会自动停止并恢复按钮。
- **显示 `Extension context invalidated`**：扩展刚被更新，刷新当前论文网页即可。
- **“打开选中段落”是灰色**：尚未选择文字，或扩展仍在恢复对应英文原文。
- **更新插件**：重新安装新版 XPI 并重启 Zotero；更新 Chrome 扩展后，在扩展管理页点击“重新加载”并刷新论文网页。

## 5. 首次使用检查与更新

1. 用自己已有的一篇论文和 PDF 测试，在 Chrome 设置中点击“保存并测试”，应提示连接成功。
2. 选择 PDF 正文中的一句话，同步后检查 Zotero 的英文高亮、中文译文、个人笔记和颜色。可以用讨论部分验证全文定位。
3. 点击“打开选中段落”，确认跳到对应位置。相邻两页的长句支持跨页高亮。
4. 更新 Zotero 端：从文件安装本包的新版 XPI 并重启。更新 Chrome 端：保留原加载文件夹路径，用新版文件覆盖后在扩展管理页点击“重新加载”，再刷新论文网页；如果改用新的文件夹加载，需要重新配对。

坐标识别覆盖 PDF 全文，首次同步需读取全文，后续会复用本机会话缓存；PDF 文件更新后会重新读取。仅支持相邻两页且两侧有足够文字的跨页匹配。纯扫描 PDF、加密 PDF、三页以上选区、网页与 PDF 版本不一致等情况可能无法定位。同步保存为 Zotero 原生 PDF 批注，不会直接覆盖原 PDF 文件；若要发送带批注 PDF，请使用 Zotero 导出功能。

1.0.0 使用独立 PDF 读取任务，避免排在 Zotero 的其他 PDF 后台工作后。单批读取超过 20 秒、整篇读取超过 90 秒或阅读器打开超过 15 秒时，会显示具体错误。Chrome 1.0.0 会提示长时间等待并显示成功耗时；若显示“保存结果尚不确定”，先检查 PDF 是否已有高亮再重试，避免重复批注。首次耗时随 PDF 大小、复杂度与电脑性能变化，不能保证每篇都在几秒内完成。

全文读取所需的 pdf-lib 已随插件打包，不需要另装插件、命令行工具或 Python。读取失败会明确报错，不会把部分页面当作全文；全文出现多处相似原文时，请选择带有更多上下文的完整句子。

把整个 ZIP 发给同事即可，不要附带你自己的配对码、浏览器配置或文库。每个人在自己的电脑上安装、配对。

## 使用条件与隐私

Zotero 端已验证 Windows + Zotero 9.0.6 / 10.0.3；网页端需要桌面 Chrome 138+。Translate Bridge for Zotero 只把批注发送到本机 Zotero；Chrome/Google 整页翻译的数据处理规则由其翻译服务决定。
