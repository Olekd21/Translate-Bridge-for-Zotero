# Translate Bridge for Zotero 用户手册

## 1.4.5：句子识别与报错区修复

- 修复图号、公式编号、e.g./i.e./vs. 等缩写误断句，句后数字引用与方括号引用归到前句；真正句界、实验数字、否定词及原始文字偏移保留。
- 修复诊断中“空”的 `<sup></sup>` 等翻译残留被当成正文交错、句尾真实引用阻断整段恢复，以及 Cre 词头与翻译后的“阴性”跨标记错位。验证来源后恢复完整句，不靠丢弃未知正文放行。
- 拖选跨入独立文献引用块时，按真实 DOM 引用身份排除该引用块；图号、无链接数字、短正文均不会按长度丢弃。若多选了没有锚点的文字，报错会直接指出该块。按钮与可编辑区域不可作为论文原文。
- 报错框不再压成细条，文字完整换行；两个诊断按钮改为同排小按钮，普通诊断不含正文，详细诊断可包含未匹配选文。侧栏拖宽、400px 最小宽度和顶部默认折叠继续保留。
- 本次修复在 Chrome 扩展中。Zotero 已是 1.4.2 或更新时只更新 Chrome 即可：重新加载扩展，将论文恢复英文、刷新，再翻译，以重建正确英文句界；无需重新配对。
- 本版提供完整安装包、Chrome 扩展与 Zotero 插件；测试未替换正式安装、未写正式文库。验证与边界见 VALIDATION-1.4.5.md；诊断重建不等于用户当前 Chrome 翻译现场已全量验收。

## 1.4.4：侧栏可调宽度，顶部区域默认收起

- 拖动侧栏左边缘可调整宽度，默认 440px，桌面最小 400px，最大为窗口宽度的 80% 且不超过 960px。松开后记住宽度，刷新或打开其他论文沿用；双击拖动柄恢复默认。聚焦拖动柄后可用左右方向键微调。
- 窗口宽度不超过 600px 时沿用全屏侧栏，避免挤出屏幕；窗口恢复后回到之前设置的宽度。
- “已有 Zotero 批注”和“文章工具”首次打开及刷新后均收起；从 Zotero PDF 选区跳到网页也不会自动展开列表。点击标题可展开；用户主动点击网页已有高亮时仍可展开对应批注卡片。
- 1.4.4 仅改进界面状态；Fig. 缩写断句及连带边界问题已在上述 1.4.5 修复。Zotero已为1.4.2或更新时，只更新Chrome扩展即可。

## 1.4.3：翻译拆句与选区一致性

- 一个英文句子被译成多个中文句子、解释从句被移到另一句时，无图号也可显示完整原句范围。检查侧栏中的完整英文及对应中文，点击“按完整英文原句定位”后再打开或同步。
- 采用后，中英文高亮范围一致；“完整英文原句范围”说明保留最初所选和补入的中文。只选择半句正文仍拒绝，不静默扩大；如果英文片段已有可靠图号对应，继续精确定位该片段。
- 不再通过宽松相似度接受不同数字、基因名称、否定含义或失效原文标记。覆盖检查保留小数点、正负号、百分号、比较符和科学符号。
- 翻译请求绑定发起时的选区，旧请求成功或失败都不修改新选区；采用整句范围后重新匹配，会核对当前页面，页面重写后需重新确认。
- CFH 原句已在该文真实 PDF 第 5 页唯一定位。浏览器流程为用户诊断重建与隔离接口替身，未替用户当前 Chrome 页面或正式 Zotero 文库完成操作；详情见 VALIDATION-1.4.3.md。
- 本地包版本为 1.4.3，未发布 GitHub。更新 Chrome 扩展、恢复英文刷新后再翻译；完整包也包含同版 Zotero XPI。原有 1.4.2 Zotero 配对与接口兼容，无需重新配对。

## 1.4.2：Nature 论文逐句专项修复

- 修复引用编号（含翻译产生的字面 `<sup>` 标签）导致整句、整段拒绝的问题；统一选区和句子组的引用过滤规则，保留基因名和实验数字。
- 修复翻译后句子标记交错及 IL / -33 跨标记漂移；恢复须满足完整中文句界、文本覆盖、明确的标记归属与原文顺序。未知来源、正文缺失、重复歧义仍会拒绝。
- 按最新需求，以完整单句、连续多句和整段为标注范围，撤掉上一版的任意词语/短语反查，不自动扩大半句选区。
- PDF 定位兼容句中引用范围（1,2,3,4 ↔ 1–4）、跨页短句尾、整页图板；重复图注句使用翻译前的英文图题消歧。
- 顶部“文章工具”默认收起，展开可使用管理待同步记录、添加到 Zotero、文章笔记和批注统计；已有批注列表可独立展开。
- 专项文章 DOI：10.1038/s44161-026-00870-y。435 个英文句段、1367 个连续多句窗口、105 个整段在真实 31 页 PDF 原生坐标中均唯一定位。该结果不等同于真实 Chrome 中文翻译后所有选区均已验证；已提供中文故障重建及旧回归另行通过，详见 VALIDATION-1.4.2.md。
- 两端均需更新到 1.4.2；重启 Zotero，Chrome 重新加载扩展后将文章恢复英文、刷新，再启用内置翻译。不需要重新配对。本次为本地包，尚未发布 GitHub。

## 1.4.1：网页阅读入口、跨节点边界与局部短语核验

- PDF 右上角及选区浮层均显示译桥矢量图标和“网页阅读”文字，避免阅读器无法加载图标图片；启动时补齐已打开 PDF，重绘后恢复，卸载时清理。
- 修复 Cdh5+ 后半句漂移到下一标记的边界；完整段落通过来源和文字覆盖校验后，无需逐句内部边界全部修复即可匹配。
- 普通标点和引用排版差异不阻断匹配；新增局部中文短语反查并核验，候选必须是原文中的连续文字；实验数字、否定表达及重复歧义不放宽。
- 局部短语路径需要 Chrome 的中译英本地语言包已可用，不会为自动重试启动额外下载；未就绪时仍保留已有匹配路径。不能保证任意中文改写或任意选区均可回写 PDF。
- 总包、Chrome、Zotero 均为 1.4.1。两端更新后重新打开 PDF；网页恢复英文、刷新后再翻译，无需重新配对。
- 实测范围及限制见 VALIDATION-1.4.1.md。本版没有发布 GitHub，也没有自动替换当前正式安装。

## 1.4.0：引用碎片、跨图页定位与文章笔记

- 修复引用链接外层在范围复制时丢失，导致碎片与整句检查结果不一致的问题；仍保留基因名、实验数值和正文。
- 修复 `IL` 与 `-33` 跨句子标记拆分后无法拼回的遗漏；按英文完整名称核验，防止误拼成不同基因。
- 含未标记正文的故障句不再让同段完整句一起失效；故障选区继续拒绝，并在边界详情中提供覆盖文字与实际范围文字，避免错误扩大选区。
- 根据本机论文 PDF 的原生抽取结果，修复显微图页标签较多时无法跨图页定位的问题。DOI 10.1038/s44161-026-00870-y 的内皮细胞两句已验证单选、合选定位到第3/5页；数字改变的反例被拒绝。
- 已有批注默认收起，标题与入口固定，列表独立滚动；卡片操作两列对齐，删除直接执行，不弹网页二次确认。
- Zotero PDF 工具栏与选中文字浮层使用译桥图标，悬停说明“网页阅读”。
- 新增“文章笔记”：不选正文也可写笔记；本地保存草稿，手动保存到对应 Zotero 文献的子笔记，再次保存更新同一笔记。文库/条目改变和并发编辑时拒绝覆盖。包含复杂格式的既有笔记保留原格式，请在 Zotero 编辑；网页编辑器使用纯文本。
- 两端统一 1.4.0。更新 Chrome 扩展及 Zotero XPI 后，将论文恢复英文、刷新，再开启翻译；无需重新配对。
- 验证边界：最新 marker 111 的完整现场 Google 翻译节点尚未取得，不能承诺所有局部中文都已恢复；新文章笔记写入经模拟接口与浏览器流程验证，未在正式文库写入测试笔记。

Translate Bridge for Zotero 用于在论文网页中阅读和做笔记，并把高亮、中文翻译和个人笔记同步到 Zotero PDF 的对应原文位置。

## 1. 安装 Zotero 插件

**Zotero 10 用户请使用译桥 Zotero 插件 1.4.0 或更新版本。** 旧版 0.6.0 的 PDF 读取指令与 Zotero 10 不兼容，可能出现配对成功、整篇能打开，但段落定位和同步一直等待。更新 XPI 后必须完全退出并重启 Zotero，清除旧请求状态；重新配对不能修复这个问题。

1. 打开 Zotero，点击顶部菜单“工具 → 插件”。
2. 点击右上角齿轮，选择“从文件安装插件”。
3. 选择安装包中的 `Translate-Bridge-Zotero-1.4.5.xpi`。
4. 完全退出 Zotero，然后重新打开。
5. 点击“工具 → Translate Bridge for Zotero → 复制配对码”。

## 2. 安装 Chrome 扩展

1. Chrome 打开 `chrome://extensions/`。
2. 开启右上角“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择安装包中的整个 `Translate-Bridge-Chrome-1.4.5` 文件夹。
5. 打开 Translate Bridge for Zotero 的“详情 → 扩展程序选项”。
6. 粘贴刚复制的配对码，点击“保存并测试”。

建议点击 Chrome 工具栏的拼图图标，把 Translate Bridge for Zotero 固定在工具栏。

## 3. 日常使用

1. 保持 Zotero 已打开。
2. 选中一篇论文，点击 Zotero 列表顶部带蓝色桥图标的“网页阅读”，或右键“Translate Bridge for Zotero · 在浏览器中阅读”。链接由系统默认浏览器打开；如果不是 Chrome，请把网址复制到 Chrome。第一次使用整页翻译前，先让英文页面完整加载一次。
3. 可以直接选择英文，也可以用 Chrome 整页翻译为中文后再选择中文。
4. 尽量选择一个完整句子或连续段落，然后点击“翻译并做笔记”。
5. 选择高亮颜色，可填写个人笔记，再点击“同步到 Zotero”。
6. 点击“打开选中段落”可定位当前段落；同步成功后会直接定位到该高亮。

“打开这篇文章”始终可用；“打开选中段落”在未选择文字时为灰色，选中并恢复出英文锚点后会变亮。

同步后的批注顺序为：个人笔记在上，中文翻译在下。`Ctrl + Enter` 可同步，`Esc` 可关闭侧栏。

在 Zotero 顶部点击“?”，或“工具 → Translate Bridge for Zotero → 开始使用与配对…”可以随时打开引导；“用户手册与依赖说明…”可离线查看完整手册。

## 4. 常见问题

- **论文整页显示 `403 Forbidden`**：表示网站拒绝本次访问，不能据此判断账号被封。稍后重新打开论文；如出现浏览器验证，在网页中完成。仍失败时，可用无痕窗口或手机网络分别对照，区分浏览器会话和网络出口问题。已下载的 PDF 可继续在 Zotero 中阅读。
- **反查原文遇到 403／429 或验证页**：扩展会说明原因，并暂停重新读取 1 分钟；读取超过 10 秒会中止网络请求。已捕获的英文段落仍可使用。

- **显示“Zotero 暂不可用”**：确认 Zotero 已打开；重新复制配对码并在扩展设置中保存测试。
- **显示“未找到文献条目”**：确认 Zotero 中已有这篇论文，DOI 或标题正确，并且论文条目下附有 PDF。
- **中文单句定位**：先确认侧栏顶部显示 **1.4.3**；没有显示则该标签页仍运行旧脚本。更新扩展后恢复英文并刷新论文页，再开启 Chrome 整页翻译。新版会提前保存句子对应关系；在对应节点被保留时，段内完整单句、连续几句均可直接恢复英文，不需要第二套翻译。请选完整句子，包括句末图号或引用。翻译拆句时可检查并采用完整原句范围；只选半句正文不会被静默扩大为整句。
- **仍未匹配**：如果整页翻译移除了句子节点，或扩展在翻译后才加载，单句对应可能无法恢复，会回退到保守翻译核验；这种情况下仍可能失败。无需重新配对 Zotero。1.4.0 的句子路径已通过重建页面测试，真实 AHA 网页与 Chrome 整页翻译链路尚未完成验证。
- **复制定位诊断**：中文定位失败时，点击状态提示下方的“复制定位诊断”。诊断包含版本、DOI、选区长度、句子缓存数量和未匹配原因，不包含正文、笔记或配对码；不会自动上传。可将它粘贴给开发者，区分边界不完整与缓存缺失等情况。
- **跨句词片段与复制反馈**：1.4.0 处理类似 `。Rev` / `-nAAC…` 的跨标记词片段：须有完整中文句末、相邻有效标记，并能在下一句英文中核实完整连字符词，才调整对应范围；不随意丢弃额外文字。复制成功提示约 1.8 秒后恢复，换选区立即重置，连续点击可重新复制。
- **复制边界详情（含当前句子）**：若原因是 `partial-sentence-boundary`，可主动点击此按钮，复制失败标记的原英文、当前中文、实际选区和前后未覆盖文字。这份详情包含当前句子正文，但不包含笔记或配对码，也不自动上传。1.4.0 修复了已复现的缓存生命周期问题，原先真实页面的边界差异仍需详情确认。
- **句子标记在但英文缓存缺失**：1.4.0 支持原段落已脱离页面时，通过同一来源且全页唯一的句子标记接回整段缓存；恢复英文时会重建失效旧标记，并防止部分翻译覆盖英文缓存。更新脚本后已丢失的英文不能凭标记凭空找回：首次更新仍请恢复英文、刷新，再翻译。无需重新配对 Zotero。
- **重启 Zotero 后插件消失**：先检查“工具 → 插件”中是条目缺失还是被禁用。通过该界面的齿轮菜单“从文件安装插件”选择正式 XPI，不要使用临时调试加载。本地版本需要手动升级；更新地址尚未发布可用元数据时不会自动获取新版。若再次消失，在重新安装前保留 Zotero 错误报告以及配置目录中译桥 XPI 是否存在的信息，用于区分文件丢失、校验失败和登记问题。
- **按钮含义**：英文选区使用“翻译成中文／重新翻译”；整页翻译后的中文选区使用“匹配英文原文／重新匹配原文”。长段落优先快速匹配，超过 15 秒会自动停止并恢复按钮。
- **显示 `Extension context invalidated`**：扩展刚被更新，刷新当前论文网页即可。
- **“打开选中段落”是灰色**：尚未选择文字，或扩展仍在恢复对应英文原文。
- **更新插件**：重新安装新版 XPI 并重启 Zotero；更新 Chrome 扩展后，在扩展管理页点击“重新加载”并刷新论文网页。

## 5. 首次使用检查与更新

1. 用自己已有的一篇论文和 PDF 测试，在 Chrome 设置中点击“保存并测试”，应提示连接成功。
2. 选择 PDF 正文中的一句话，同步后检查 Zotero 的英文高亮、中文译文、个人笔记和颜色。可以用讨论部分验证全文定位。
3. 点击“打开选中段落”，确认跳到对应位置。相邻两页的长句支持跨页高亮。
4. 更新 Zotero 端：从文件安装本包的新版 XPI 并重启。更新 Chrome 端：保留原加载文件夹路径，用新版文件覆盖后在扩展管理页点击“重新加载”，再刷新论文网页；如果改用新的文件夹加载，需要重新配对。

坐标识别覆盖 PDF 全文，首次同步需读取全文，后续会复用本机会话缓存；PDF 文件更新后会重新读取。仅支持相邻两页且两侧有足够文字的跨页匹配。纯扫描 PDF、加密 PDF、三页以上选区、网页与 PDF 版本不一致等情况可能无法定位。同步保存为 Zotero 原生 PDF 批注，不会直接覆盖原 PDF 文件；若要发送带批注 PDF，请使用 Zotero 导出功能。

1.4.0 使用独立 PDF 读取任务，避免排在 Zotero 的其他 PDF 后台工作后。单批读取超过 20 秒、整篇读取超过 90 秒或阅读器打开超过 15 秒时，会显示具体错误。Chrome 1.4.0 会提示长时间等待并显示成功耗时；若显示“保存结果尚不确定”，先检查 PDF 是否已有高亮再重试，避免重复批注。首次耗时随 PDF 大小、复杂度与电脑性能变化，不能保证每篇都在几秒内完成。

全文读取所需的 pdf-lib 已随插件打包，不需要另装插件、命令行工具或 Python。读取失败会明确报错，不会把部分页面当作全文；全文出现多处相似原文时，请选择带有更多上下文的完整句子。

把整个 ZIP 发给同事即可，不要附带你自己的配对码、浏览器配置或文库。每个人在自己的电脑上安装、配对。

## 使用条件与隐私

Zotero 端已验证 Windows + Zotero 9.0.6 / 10.0.3；网页端需要桌面 Chrome 138+。Translate Bridge for Zotero 只把批注发送到本机 Zotero；Chrome/Google 整页翻译的数据处理规则由其翻译服务决定。

## 网页显示已有 Zotero 批注（1.4.0）

同时更新浏览器扩展和 Zotero 插件到 1.4.0，打开 Zotero，再刷新论文网页。带 DOI 的论文会自动读取批注；也可打开译桥侧栏，在“已有 Zotero 批注”中点击“刷新批注”。无需重新配对。

- 读取匹配论文下所有 PDF 附件中的非删除批注，显示原文、备注、颜色和页码。
- 网页唯一匹配到的文字显示原色高亮/下划线，点击标记打开对应批注卡；卡片可跳回 Zotero。
- 翻译后的网页仅恢复已通过完整句边界校验的对应位置。文字重复、中文边界漂移、跨段无法定位和非文字批注保留在侧栏，不猜测位置。
- 在 Zotero 修改或删除批注后，点击“刷新批注”重新读取；也可在卡片中编辑评论或直接删除批注，修改会同步到 Zotero。
- 此版本不保证任意中文局部选区恢复；之前 Nature 中文跨标记故障仍待真实页面证据验证。

## 1.3 新增操作

- 点击网页高亮可展开批注列表并滚动到对应卡片；重叠批注再次点击可切换。
- 批注卡片“编辑内容”修改的是评论（包括原有译文和笔记），不会修改PDF引用原文和坐标。保存为纯文本。Zotero中内容已变化时会拒绝覆盖，保留输入；删除无需网页二次确认，会直接同步删除 Zotero 原批注。
- “管理待同步记录”打开扩展设置，支持查看、单条移除及清空；只取消本地待同步任务，不删除已保存的Zotero批注。
- Zotero PDF阅读器工具栏与选中文本浮窗均有“网页阅读”。点击选区入口后在默认浏览器打开网页，由已配对的译桥定位对应文字；建议使用Chrome为默认浏览器。无全文、未配对或无法可靠映射时显示失败，不保证所有网页都能定位。
- “添加到 Zotero”保存网页提供的标题、DOI、作者等信息到个人文库，并让Zotero尝试获取可用PDF。重复DOI或同URL不重复创建。它不代替网站专用抓取器；缺失的元数据、付费全文可用Zotero Connector补充。条目保存成功不代表PDF下载成功。
- 一条英文被译成多条中文时，支持用唯一且完整的图号边界恢复对应英文子句；没有充分边界证据时仍可能拒绝，不按字符比例猜测。
