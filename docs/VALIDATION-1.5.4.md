# Translate Bridge for Zotero 1.5.4 验证记录

## 用户本次要求

只有主动点击才记录；记录时不要填写原因，直接保存错误代码、定位诊断及文章选区。

## 实现

- 删除网页状态警告、操作失败及设置页警告中的自动写入。错误回调最多保留当前错误上下文于内存，不生成局部 DOM 诊断、不写入问题库；迟到响应不覆盖新的选区上下文。
- 网页侧栏和设置页的“记录当前问题”直接保存，无 prompt、无原因输入。保存期间禁用按钮，保存结果在按钮旁显示。中文定位问题使用诊断中的实际失败代码，不以 manual 覆盖。
- 保留 JSON 导出/导入、首次和最近证据、原位置回访、人工复核状态及可选备注。旧数据不删除、不迁移；既有记录只有再次主动记录才累计次数或重新打开已解决状态。
- 只调整收集入口，保留既有句子来源校验、高亮稳定性和 Zotero 跳转行为。

## 实际入口验证

使用 Playwright CLI、全新 E 盘隔离 Chromium 配置及真实 MV3 扩展，运行 scripts/test-issue-workflow-browser.js，7 组断言通过：

1. 触发中文映射失败后问题库为 0 条；点击后为 1 条，无输入对话框。
2. 再次匹配失败，存储逐字相同；再次主动记录才累计为 2 次。
3. 保存的错误代码为 invalid-sentence-fragment-groups，并含来源关联证据、选区和局部段落结构。
4. 设置页失败不会新增记录；点击才保存设置诊断，不读取配对码。
5. 管理页复核备注经刷新保留，实际导出 output/playwright/issues154-export.json。
6. 回访新标签，中文出现后查找恢复精确选区，人工复核记录 1.5.4 版本；变化/重复选区拒绝误定位。
7. 用户之前的 Nature 1.5.2 诊断仍可主动导入。
