# 1.4.5 句子识别与报错区修复

日期：2026-10-03。用户重新明确授权继续句子识别修复，并补充整段失败、额外短块、Cre 词头漂移与报错布局截图。本版包含 1.4.4 的拖宽侧栏、400px 最小宽度和顶部默认折叠。

## 根因与实现

- 英文捕获直接接受 Intl 的缩写误断句，导致 `Extended Data Fig. 4).` 被拆为两段，中文前缀修复因后段没有句末而无法成立。现在对有明确续接证据的图/公式/章节编号、e.g./i.e./vs.、姓名头衔等保护点号；et al. 仍保留真正句末。仅在分割临时字符串中等长屏蔽，最终片段从原文索引回取，文字与 UTF-16 偏移不变。句后数字和方括号引用归前句，英文候选路径使用同一分割入口。
- 空壳 `<sup></sup>` 等字面翻译残留在诊断中显示为空，分组却用 raw.trim() 判非空；统一使用阅读文本归一化筛空，保留独立数字逗号、冒号、prime 等科学符号。交错恢复的段尾检查改用原 DOM 引用过滤范围，避免真正引用38阻断整段。
- `Cre-negative` 后半词翻成“阴性”后不再提供 Latin 续片。仅当移位前缀精确等于下一英文句首连字符复合词的完整首组件时允许归回，不能匹配更长组件、单字母或只出现在句中的词。
- 独立引用块只有在原 DOM 已证实引用身份且其全部文本均属引用时才能排除；整个选区和分块使用同一排除范围。引用身份限定明确角色、同文档已识别数字文献锚点或真实文献列表目标。混合引用/图号/普通数值不能互相借用引用身份。未知短正文、无链接数字、图号和实体链接不按长度丢弃。
- 控件与可编辑内容不可作为科学原文，跨入控件明确提示重选；正文旁按钮不会自动使独立正文句失效。额外无锚点块显示具体文字，详细诊断可包含该块正文，普通诊断中的失败对象仅保留原因和标记。
- 同段重复原句各自定位可能有歧义，但逐标记来源有效、选区完整覆盖、恢复出的整个句序列精确等于原段落时，可以恢复完整段落；未放开单句歧义。
- 报错区域不再被 flex 压扁，文本完整换行；两诊断按钮改为同排次级小按钮，错误出现时底部独立滚动到可见位置。
