# Translate Bridge for Zotero 0.7.0

连接 Chrome 内置 Google 翻译与 Zotero：阅读翻译后的论文网页，将选中文字匹配回 PDF 英文原文，并同步高亮、中文译文与笔记。

## 下载与安装

推荐下载 **translate-bridge-for-zotero-0.7.0.zip**，解压后打开 **START-HERE.html**。完整包包含 Chrome 扩展 0.7.0、Zotero 插件 0.5.0 和离线用户手册。无需安装开发工具或配置 AI API key。

Chrome 扩展尚未上架应用商店，需要在扩展管理页开启开发者模式并选择“加载已解压的扩展程序”。Zotero 端通过“从文件安装插件”安装 XPI，然后按手册配对。

## 本次改进

- Zotero 新增带图标的“网页阅读”按钮、右键入口和首次使用引导。
- 修复符合条件的相邻两页长句无法定位的问题。
- 改善网站 403、429、验证页与请求超时的提示和重试处理。
- 用户手册明确安装依赖、配对、更新方法与常见问题。

## 使用范围

已验证 Windows + Zotero 9.0.6；Chrome 需 138+。PDF 定位目前覆盖前 5 页，需要可检索的文字层。跨页匹配要求相邻两页均在读取范围内；网页与 PDF 版本不一致、纯扫描文件等情况可能无法定位。其他操作系统与 Zotero 版本尚未完成同等实机验证。
