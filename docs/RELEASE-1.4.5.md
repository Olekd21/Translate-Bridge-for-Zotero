# 译桥 1.4.5：句子识别修复与侧栏改进

## 本次重点

- 修复 Fig.、公式编号及 e.g./i.e./vs. 等缩写误断句；句后引用归到前句，保留真正句界与原始字符偏移。
- 修复空翻译标记、交错引用、句尾引用及 Cre-negative 词头漂移引起的整句或整段定位失败。恢复仍需通过来源、顺序和文字覆盖校验。
- 拖选跨入独立文献引用时按 DOM 身份识别引用；未知短正文、图号和真实数值不按长度丢弃。未匹配块会给出具体提示。
- 侧栏可拖宽并记忆，桌面最小 400px；“已有 Zotero 批注”和“文章工具”默认收起。错误提示可完整换行，诊断按钮同排紧凑显示。

## 相比上一公开版本 1.2.0

包含已有批注编辑/删除、文章笔记、待同步队列管理、文章添加及 Zotero 阅读器跳转网页入口。一个英文句子被译成多个中文句子时，可预览并明确确认采用完整英文原句范围；不会静默扩大选区。继续改进引用范围、跨页及科学符号的 PDF 定位。

## 下载与升级

- **推荐下载 `translate-bridge-for-zotero-1.4.5.zip`**，解压后打开 `START-HERE.html`。
- `translate-bridge-chrome-1.4.5.zip`：Chrome 扩展，解压后加载。
- `translate-bridge-zotero-1.4.5.xpi`：Zotero 插件。
- GitHub 自动附带的 Source code 压缩包是源码，不是完整安装包。

从 1.2.0 升级须同时更新两端。Zotero 安装 XPI 后完全退出并重启；Chrome 重新加载扩展后，**将论文恢复英文、刷新，再开启整页翻译**，以重建原文缓存。通常无需重新配对。Zotero 已为 1.4.2+ 时，可仅更新 Chrome 至 1.4.5。

## 验证与限制

152 项自动测试及 PDF 几何检查通过；英文分句 42 项、故障重建与浏览器布局回归通过。对本次 Nature 论文缓存原文，105 块/429 句捕获通过；使用对应 31 页 PDF 原生坐标验证，429 单句、1313 连续多句和 105 整段均唯一定位，未创建文库批注。
