# 译桥 1.5.5：Google 翻译句子对应与本地问题记录

## 主要变化

- 统一翻译前英文快照的断句和网页字符偏移，修复引用换行造成整段没有句子锚点的问题。
- 使用有宽度限制的整句容器，减少 Google 翻译跨句移动标记；修复句末参考文献、科学上下标附近的错位和厂家缩写误断句。科学上下标继续参与整句翻译；容器可能使文本更频繁换行。
- 英文长句被译成几个中文句子时，提供完整原句与完整译文供确认；不会悄悄扩大选区或用近似英文代替原文。
- 相比上一公开版 1.4.5，减少网页无关更新触发的批注刷新和重复扫描，改善高亮闪烁、删除后残留，以及 Zotero 网页阅读按钮的点击响应。
- 新增本地问题库：仅点击“记录当前问题”才保存错误代码、定位诊断、版本和选区，无需填写原因；支持 JSON 导出、回访原位置、手动标记“已解决／仍有问题”。不自动上传、不自动记录每次失败。

## 下载与升级

- **首次安装或从 GitHub 1.4.5 升级：推荐下载 `translate-bridge-for-zotero-1.5.5.zip`，同时更新两端，解压后打开 `START-HERE.html`。**
- `translate-bridge-chrome-1.5.5.zip`：Chrome 扩展；本地已使用 1.5.4 时，此次仅需更新它。
- `translate-bridge-zotero-1.5.5.xpi`：Zotero 插件，安装后完全退出并重启 Zotero。
- GitHub 自动生成的 Source code ZIP/TAR 是源码，不是完整安装包。

**Chrome 请用新文件覆盖原加载目录，再在扩展管理页点击“重新加载”，不要卸载，以保留本地问题记录。** 变更加载目录或清除数据前先导出问题库。已翻译的论文应恢复英文、刷新，再启用 Google 翻译，以重建句子来源；通常无需重新配对。

## 验证范围

对文库链接对应的 PMC 全文（DOI `10.1002/ctm2.374`），使用 Chrome 原生 Google 翻译验证摘要、正文和图注：

- 48 个文字块、356 个英文来源句完整恢复。
- 364 个中文选句：348 个直接对应，16 个须确认采用完整英文长句。这 16 个来自 8 个被 Google 拆开的英文长句。
- 316 个相邻双句选区通过；真实 1.5.5 MV3 扩展回放实际译文后，48 段与 364 句的侧栏检查共 412/412 通过。
- 175 项项目自动测试、344 项跨领域 DOM 结构测试、46 项完整原句范围测试和 7 组手动问题记录流程检查通过。
- 无关页面更新测试中，额外批注请求、文本遍历与高亮缺失均为 0；200 段／600 来源句／25 次替换性能回归通过。

原生 Google 层使用隔离浏览器及断开的 Zotero 测试接口，真实 MV3 层回放其译文；不是用户正式 Chrome 与 Zotero 联合运行的逐句 PDF 写入验收。其他领域的结构测试不代表翻译语义全量验证，也不保证所有网站及以后 Google 改版永久成功。详见 [1.5.5 验证报告](https://github.com/Olekd21/Translate-Bridge-for-Zotero/blob/v1.5.5/docs/VALIDATION-1.5.5.md)。
