# 译桥 1.0.1：中文选区回查与重启核查

2026-09-26。Chrome、Zotero 和总版本统一为 1.0.1。发行附件为 Chrome ZIP、Zotero XPI 和完整 ZIP，不提供安装器。

## 中文选区改动

针对 DOI `10.1161/JAHA.125.047618` 的截图故障和“其他论文也只有中文无法定位”的反馈，修复浏览器端原文恢复：

- 从 `document_start` 开始记录英文，并观察新文字节点及文本修改，减少扩展加载晚于整页翻译造成的缓存缺失。
- 支持不含下级正文块的 `div`，以及标准段落内部的翻译包装。此前只识别 `p/li/...`，公共祖先不在列表中会产生无效段落索引。
- 按真实 Range 边界裁剪文字块，逐块恢复后组合；有文字未被覆盖则拒绝整个映射，不同步残缺结果。
- 节点被替换时可使用唯一稳定 ID 找回已缓存英文；重新请求原页时也必须按唯一 ID 对应，取消按全页段落序号猜测。原文缓存按文章 URL 隔离，章节锚点不会清空缓存。
- 只有完整已缓存段落直接映射；选中超过半段、句子数量相近或句子相对位置不再被当作可靠依据。短句通过本地翻译核验并比较候选差距，低相似度、歧义、超时均保留未匹配状态。

更新后必须重新加载 Chrome 扩展，并先恢复英文、刷新论文页，再进行整页翻译。已有已翻译标签页不能凭空补回没有保存的原文。无原文缓存且无稳定 ID 的页面会给出具体恢复步骤；短句需要 Chrome 本地 Translator 语言包，整段缓存路径不需要再次翻译。

## 实际验证

- 53 项命名回归与原有 PDF 几何套件通过；版本、资源、ZIP/XPI 完整性、个人配置不打包等校验通过。
- 9 项真实 Chromium DOM 测试通过：div、p、数字句、跨块、替换节点、无 ID 的已缓存块、段落中的 div 包装、翻译后才加载扩展且段落顺序改变、短句核验。
- 浏览器测试使用用户提供截图中的中文和用户库里该论文 PDF 第 3 页的真实英文，页面结构是重建测试夹具，Chrome 扩展 API/短句翻译 API 是模拟接口。AHA 原网址在直接读取和独立浏览器中均返回验证页/403，因此**没有完成 AHA 实际页面 + Google 整页翻译的完整浏览器验收**。
- 将浏览器测试实际恢复出的 4 个英文选区及中文译文交给最终原样 XPI，在独立 Zotero 9.0.6、10.0.3 文库各创建 4 条原生批注，全部唯一匹配第 3 页。运行的是实际 Zotero 服务处理函数，不把它描述为浏览器到 HTTP 的完整点击链路。
- 最终原样 XPI 在两版环境各完成 4 轮启动（首次安装及 3 次重启）；后续轮次没有重装或重新启用。每次均为 `temporary=false / active=true`，服务响应正常，4 条批注持续存在。结束后只读 SQLite 再确认两库各 4 条、页码 3、中文译文与坐标均落盘。
- 测试辅助插件只用于独立配置中通过 AddonManager 永久安装正式 XPI、读取状态和调用处理函数；辅助插件自动启用设置仅存在于测试配置，未改动用户正式配置的启用策略。启动目录扫描使用运行时默认设置。

最终证据：`.cache/rematch-browser-results.txt`、`.cache/build-1.0.1-final.txt`、`.cache/restart-audit-1.0.1-delivery/`（单轮 JSON、汇总、SQLite 复核）。两份运行安装副本与交付 XPI 的 SHA256 完全一致。

## 重启后插件消失：已确认与未确认

只读检查时，用户正式 Zotero 中的 1.0.0 正在启用，位于永久 `app-profile` 目录，`temporary=false`、无待执行卸载操作。该会话没有找到译桥清单校验错误。因此**尚未确定用户此前重启消失的具体原因，不能宣称已根治**。

检查发现旧包更新地址仍指向旧仓库，返回 404。1.0.1 已修正仓库及 XPI 附件命名；发布校验要求必要的 `update_url` 存在且指向本项目。新版本尚未发布在线更新元数据，当前仍需手动安装。

独立测试中确实观察到：缺少 `applications.zotero.update_url` 的测试辅助包被 Zotero 判为无效并移除；修正辅助包后正常。用户当前 1.0.0 有该字段，这不是用户事故的已证实根因。404 与字段缺失不同，也不能据此断言旧更新地址导致卸载。初期辅助包缺字段、探针阻塞加载顺序、测试把成功创建的 HTTP 201 当作失败等测试脚本问题均已修正；最终验收以上述 delivery 目录为准。

保留了正式安装的只读基线 `.cache/formal-bridge-baseline-20260926.json`。若再次消失，应在重装前保留插件目录中 XPI 是否存在、`extensions.json` 中是否登记以及 Zotero 错误报告，才能区分文件被移除、无效清单和登记问题。不自动重装掩盖原因。
