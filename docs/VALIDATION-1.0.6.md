# 1.0.6：实际边界词片段与复制反馈修复

用户 1.0.5 的真实边界详情确认：选中完整的“主动脉缩窄的前4周……（图2A）。”，缓存英文也对应完整第一句，但中文标记末尾额外含下一句开头的 `Rev`；`omittedAfter` 正是 `Rev`。因此选第一句被误判未完整覆盖，选择下一句又会跨入前一标记。

现在为相邻标记建立逻辑范围：只有前一句在中文句末后多出短拉丁词片段、下一标记以连字符词续接，且完整词可在下一句英文中核实，才将该片段划归下一句。实现不针对 DOI 或 Rev-nAAC 作白名单，也不将一般半句扩大为整句。

复制诊断与边界详情的成功/失败提示约 1.8 秒后恢复；换选区立即重置。每次点击重新生成报告，异步旧请求不能覆盖新选区提示。另对“两句中文挤进一个标记而相邻英文标记变空”的模拟异常拒绝直接映射，防止只恢复一半英文。
