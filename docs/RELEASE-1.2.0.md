# 译桥 1.2（1.2.0）更新说明

本次合并自上一公开版本1.0.6以来的功能与修复，Chrome、Zotero和完整包统一为1.2.0。

## 新功能：网页显示 Zotero 已有批注

打开论文后，在“已有 Zotero 批注”中查看原文、笔记、颜色和页码。能可靠定位的文字在网页上标记，点击可查看笔记；不能定位的批注保留在侧栏。点击“刷新批注”读取 Zotero 中的新改动。此功能只读已有批注。

## 修复：中文选句、PDF定位与同步

- 改进 Chrome 整页翻译后的句子边界、跨标记片段、克隆节点、数字引用和英文缓存恢复。
- 诊断仅在出错时出现；复制诊断/边界详情后提示自动恢复，换选区可再次复制。
- PDF定位改进跨栏、跨页和部分稀疏图页间隔处理；修复断行与英美拼写替换冲突，以及引用数字坐标偏移。
- 对比正文内容而非要求字符格式完全相同，但不忽略科学数字、基因名、否定词；多处匹配仍拒绝自动写入。
- 状态提示区分“找回英文原文”和“PDF定位成功”；独立PDF读取任务带超时处理。
- 跨页高亮分开保存，失败时撤销本次已经创建的部分，避免残留半条批注。

## 必须这样升级

1. 下载下面的 **translate-bridge-for-zotero-1.2.0.zip** 完整安装包，解压后打开 START-HERE.html。
2. 在 Zotero 插件管理中安装 **Translate-Bridge-Zotero-1.2.0.xpi**，完全退出再启动 Zotero。
3. 更新 Chrome 已加载的扩展文件夹，重新加载扩展；确认侧栏版本为 **1.2.0**。
4. 将已翻译的论文恢复为英文，刷新页面，再开启 Chrome 整页翻译。一般无需重新配对。

也提供单独 Chrome ZIP 与 Zotero XPI。不要把 GitHub 自动生成的 Source code ZIP 当成安装包。没有安装器，不依赖 Better Notes。

## 验证结果与尚存限制

- 本地文库抽16篇，959个候选文本块中859个实际执行，845个唯一匹配且页码/段落矩形相符；12个未匹配、2个歧义。两篇加密PDF的100个候选未执行。
- 最近一轮修复新增找回12处；最终1.1.4构建在隔离 Zotero9.0.6及10.0.3中均成功保存这12处高亮。1.2.0沿用相同功能代码，更新统一版本号和说明。
- 60个改动科学数值的反例全部拒绝；保留正式文库和原始PDF。
- 1.2.0发布构建运行全部自动回归、扩展检查、TypeScript编译及安装包完整性/版本一致性检查。
- 加密PDF、特殊字体编码、重复文字仍可能无法定位；只有可可靠映射的已有批注会在网页正文标记。
- PDF语料测试不等同于所有网站的真实Chrome翻译DOM验证，不能保证任意半句、任意网页都成功。
