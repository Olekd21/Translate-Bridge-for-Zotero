# Translate Bridge for Zotero 1.4.6 验证记录

## 本版目标

1. 英文正文保持为定位真相源，中文显示在独立阅读层中，避免 Chrome 整页翻译改写 DOM 后产生非连续 marker、空上标和句界漂移。
2. 中文句子通过扩展生成的稳定编号直接关联英文句子，可继续打开 PDF 位置和同步 Zotero。
3. 删除批注后不再因网页重绘或短暂的旧接口结果而闪回划线。

## 已完成验证

- `node --check packages/browser-extension/content.js` 与扩展清单一致性检查通过。
- 真实 Chromium 页面验证了中文、对照、原文三种模式；`p` 与文章主体内叶子级 `div` 正文均被识别，中文模式没有遗留可见英文段落。
- 模拟译文验证 `α-SMA+`、`VEGFR-3 f/−`、`TUNEL+` 均原样恢复；中文阅读层没有 `<sup>` 字面字符串或嵌套 `sup` 节点。
- 选中安全阅读层中的完整中文句子后，侧栏显示对应英文原文、“安全英文锚点”和“独立中文层”，无需调用旧的中文反查路径。
- 删除批注后卡片与 CSS Highlight 立即归零；接口继续返回一次旧批注并触发网页重绘时仍保持为零，接口确认删除后继续为零。
- 完整 `build:release` 通过：152 项自动测试全部通过，Zotero TypeScript 检查与 XPI 构建通过。
- 三个产物版本均为 1.4.6；Chrome ZIP 与完整包中的 `content.js` SHA256 均与最终源码一致。最终包的字节数和哈希记录在项目进度检查点中，避免验证文件引用其所在 ZIP 的自哈希。

## 验证边界

- 浏览器验证使用隔离页面和确定性的 Translator API 替身，用来检查 DOM 隔离、模式切换、科学字符保护及句子关联。尚未替用户在目标期刊页面下载真实 Chrome 语言包或写入正式 Zotero 文库。
- 安全阅读当前覆盖普通正文段落、图注、引用块和文章主体内叶子级 `div`；表格、复杂公式、交互图和 Shadow DOM 不作为本轮试用范围。
- 本版为本地试用包，未发布 GitHub，也未自动替换用户当前安装。
