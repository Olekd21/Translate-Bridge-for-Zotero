# 译桥依赖、卡顿与 Zotero 10 兼容性核查

结论：旧 Zotero 插件 0.6.0 在 Zotero 10.0.3 上存在已复现的 PDF 读取协议不兼容。修复包为 Chrome 0.8.1 + Zotero 插件 0.6.1。不能由此前 Zotero 9 的单机测试推定支持 Zotero 10。

## 根因与证据

旧译桥使用 `getRecognizerData`；Zotero 10 改用 `pdf.getRecognizerData`。`_enqueue` 和 `_query` 方法仍存在，所以旧版的方法存在性检查无法发现问题。只装旧译桥的 Zotero 10.0.3 临时文库中，配对 HTTP 200，但同步一直等候旧指令，20 秒测试客户端超时后 worker 仍未返回。

官方源码：[Zotero 10 PDF manager](https://raw.githubusercontent.com/zotero/zotero/10.0/chrome/content/zotero/xpcom/pdfWorker/manager.js)。测试程序来自 [Zotero 官方下载页](https://www.zotero.org/download/) 的 Windows 64 位 ZIP；运行前核验了 Windows 有效数字签名。没有升级用户的正式 Zotero。

## 独立运行与最终安装包实测

分别使用独立的 profile、数据库、PDF 副本与本地端口。唯一启用的第三方扩展为译桥，未安装 Better Notes、LLM、PDF Translate 等。最后一次验收直接安装交付 XPI，未附加测试启动脚本；文件 SHA-256 与交付 XPI 一致。

测试使用公开论文 DOI `10.1186/s12931-024-02846-7` 的 11 页 PDF，第 2 页引言选段。通过真实 HTTP 接口依次调用配对、整篇打开、定位、创建高亮、重复定位。

| 最终交付包测试 | Zotero 9.0.6 | Zotero 10.0.3 |
|---|---:|---:|
| 整篇打开 | 0.096 秒 | 0.019 秒 |
| 首次定位，完整读取 11 页 | 1.258 秒 | 0.678 秒 |
| 创建原生高亮、中文译文与笔记 | 0.136 秒 | 0.143 秒 |
| 再次定位，复用缓存 | 0.063 秒 | 0.075 秒 |

这是一篇 PDF、同一台电脑、库已完成启动的实测值，不是任意 PDF 的性能承诺。首次运行新临时库时还观察到阅读器等待文库初始化；重启并等待加载后完成验收，不将测试准备期间的等待直接认定为朋友环境的根因。

最终测试进程关闭后，使用只读 SQLite 查询确认批注已落盘：highlight 类型、第 2 页、5 行坐标、完整原文、中文译文与个人笔记。用户正式文库和原 PDF 均未改动。

## 本次修复

- 识别 Zotero 原生读取实现的新旧协议，未知协议明确报错。
- 为译桥创建独立的原生 PDF worker，避免等待共享 PDF 队列；只终止自身 worker。
- 单批读取 20 秒、整篇读取 90 秒、阅读器打开 15 秒超时；浏览器也限制请求等待时间。
- 保留全文读取、按文件变动失效的缓存、唯一匹配和歧义拒绝规则。
- 配对结果显示 Zotero 与插件版本，成功提示显示耗时；慢请求显示等待说明。
- 拦截进行中的重复点击，切换选段后不让旧请求覆盖新选区状态。
- 同步超时而保存结果未知时不自动入队重试；提示先核对批注，减少重复写入风险。这不等同于跨重启的幂等保证。

## 回归与边界

29 个命名自动测试以及几何匹配套件通过，覆盖断词、双栏、跨页、第 13 页、重复文本歧义、缓存、文件变化、损坏 PDF、新旧协议、挂起超时、重复点击与选区切换。TypeScript、修改过的 TypeScript 文件 ESLint/Prettier、Chrome JavaScript 语法与 manifest 校验通过。完整包核验通过，含两端版本、资源、离线手册、许可证、空配对默认值与个人文件排除。

完整项目 Prettier 另有原有文件格式告警，未为本次修复重排无关文件。

真实浏览器自动加载测试扩展的命令被自动审批拦截，工具仅返回 `blocked by policy`。Chrome 侧本轮验证为逻辑/语法回归；未宣称完整浏览器点击到 Zotero 的自动验收已完成。其他 Zotero 小版本及 macOS/Linux 未逐一实测。

安装包：`dist/translate-bridge-for-zotero-0.8.1.zip`，333329 字节，SHA-256：`65d99cec736231f87868eaae0d576c99b1f27f3d0cc4183687dbcd2f5304c9dc`。

本机证据保留在 `.cache/zotero10-old/`、`.cache/zotero9-fixed/`、`.cache/zotero10-fixed/` 的 HTTP 结果和数据库复核文件；这几个目录不进入分发包或 Git。

## 使用修复包

Zotero 从文件安装 0.6.1 XPI 后完全退出并重启；Chrome 更新为 0.8.1、重新加载扩展并刷新论文页。无需补装其他插件或降级 Zotero。安装包发布在 [v0.8.1 Release](https://github.com/Olekd21/Translate-Bridge-for-Zotero/releases/tag/v0.8.1)。
