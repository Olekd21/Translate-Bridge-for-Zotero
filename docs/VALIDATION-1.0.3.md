# 1.0.3 句子定位扩展测试（2026-09-26）

用户在 1.0.2 中反馈 AHA Results 段首连续两句仍失败，要求扩大测试并避免遗漏。以下是本地测试范围，不是所有网站兼容性保证。

## 已发现并修复

- 带 ID 的共同祖先被误认为会被拆分克隆，导致安全的句子也被跳过。
- 句末空白落在行内元素之外，导致不必要地跨越带 ID 的边界。
- 翻译克隆替换节点后 WeakMap 缓存丢失：现在允许同一段落中唯一句子标记恢复原文；跨段标记和重复标记不能用该方式恢复。
- 未验证的句子标记曾可被整段快速匹配绕过；现在回退必须继续核验，不能将改动后的文字直接映射为旧整段。
- 支持正文中的完整内联 MathML 公式，不再因为出现公式而跳过整个段落。

新增失败时的“复制定位诊断”，只复制版本、DOI、字符数、句子缓存数量和失败原因，不含正文、笔记或配对码，不自动上传。

## 边界

这些测试在 Chromium 中运行真实 DOM、选择范围和译桥脚本。AHA 测试中文来自用户截图，其余跨领域测试使用中文占位句，目的是验证缓存和范围对应，**不验证机器翻译语义、真实 Google 翻译 DOM 行为或这 129 句到 Zotero PDF 的同步链路**。跨领域句子由 Intl.Segmenter 预分段，因此也不是对其科学缩写分句准确性的独立验证。

截图故障与以上缺陷相关的可能性较高，但缺少失败页面的 DOM 诊断，不能宣称已确定该截图的唯一根因。1.0.3 当前为本地测试包；真实页面反馈仍需确认。如有失败，使用“复制定位诊断”获取具体分支，避免盲目调整匹配阈值。
