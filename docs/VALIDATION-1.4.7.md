# Translate Bridge for Zotero 1.4.7 验证记录

## 本版目标

1. 中文阅读继续使用 Chrome 自带的 Google 整页翻译，不生成额外中文副本，也不为整篇文章逐段调用本地 Translator API。
2. 英文页面翻译前为每个句子记录稳定句序。即使同一英文句子在一个段落中重复出现，也能按出现位置恢复原文。
3. 保留完整句覆盖、来源归属和原文顺序校验；旧缓存没有句序且原句重复时继续保守拒绝。
4. 保留 1.4.6 已修复的 Zotero 删除批注后网页划线闪回防护。

## 已完成验证

- `node --check packages/browser-extension/content.js` 通过。
- 英文分句专项测试 44 项通过，包括“重复英文句按句序解析到第一次/第二次出现”和“旧缓存遇到重复原句时保守失败”。
- 真实 Chromium 隔离页回归中，在同一段连续放置两句完全相同的 `Expression increased.`，模拟 Google 翻译后分别显示“表达升高。”和“表达也升高。”；选择第二句中文时，侧栏准确恢复 `Expression increased.` 并显示第二句中文。
- 同一浏览器回归确认 1.4.6 的“安全中文阅读”按钮不存在，页面没有 `.pb-safe-translation` 中文副本或 `[data-pb-safe-source]` 正文标记。
- Chrome 扩展清单检查、154 项完整自动化回归、Zotero TypeScript 检查和 XPI 构建全部通过。
- 三个 1.4.7 产物均已生成；Chrome 分包和完整包中的 `content.js` SHA256 均为 `84C1B46C11461B957793C040601EB1F3E4EC23F5D3C541F7B2D545C4A920E136`，与最终源码一致。

## 使用与迁移

- 更新 Chrome 扩展后，先把已翻译论文恢复为英文并刷新一次，让 1.4.7 从英文原页建立句序；随后照常使用 Chrome 的“翻译成中文”。
- 旧页面在 1.4.7 加载前已经被翻译时没有新的句序信息，不能由本版可靠补建，应恢复英文并刷新。
- Zotero 端已为 1.4.2 或更新版本时可只更新 Chrome 扩展，无需重新配对。

## 验证边界

- 重复句、碎片和翻译后 DOM 的浏览器回归使用本地隔离页面模拟 Google 翻译改写；目标期刊的真实 Google 翻译结果仍需在用户浏览器试用。
- 本版不会放宽未知来源、正文缺失、非连续标记或原文顺序冲突；这些情况仍会显示诊断，而不会猜测对应关系。
- 本版为本地试用包，未自动替换当前安装，也未发布 GitHub。
